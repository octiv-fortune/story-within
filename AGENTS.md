## Agent skills

### Issue tracker

Track issues and specs as local Markdown files under `.scratch/<feature>/`. Before creating or reading tickets, see `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage roles. Before triaging an issue, see `docs/agents/triage-labels.md`.

### Domain docs

Use a single-context layout: root `GLOSSARY.md` and `docs/adr/`. Before exploring the codebase, see `docs/agents/domain.md`.
